This guide gets you from zero to a live stream in under 5 minutes. You will run SRS with Docker, publish a stream, and play it back using multiple protocols.

## Prerequisites

- [Docker](https://docs.docker.com/get-docker/) installed and running
- Optional: [FFmpeg](https://ffmpeg.org/download.html) or [OBS Studio](https://obsproject.com/download) for publishing

<Steps>

<Step title="Run SRS with Docker">

Pull and start the SRS container with all standard ports exposed:

```bash
docker run --rm -it \
  -p 1935:1935 \
  -p 1985:1985 \
  -p 8080:8080 \
  -p 8000:8000/udp \
  -p 10080:10080/udp \
  ossrs/srs:6
```

Once started, open [http://localhost:8080/](http://localhost:8080/) in your browser to confirm SRS is running.

<Tip>
If you are in China, use the Alibaba Cloud mirror for faster download speeds:

```bash
docker run --rm -it \
  -p 1935:1935 \
  -p 1985:1985 \
  -p 8080:8080 \
  -p 8000:8000/udp \
  -p 10080:10080/udp \
  registry.cn-hangzhou.aliyuncs.com/ossrs/srs:6
```
</Tip>

</Step>

<Step title="Publish a stream">

Choose your publishing method:

<Tabs>
  <Tab title="FFmpeg">
    Publish a local media file as a looping live stream. The `-re` flag reads the input at its native frame rate to simulate a live source, and `-c copy` avoids re-encoding.

    ```bash
    ffmpeg -re -i ./doc/source.flv -c copy -f flv -y rtmp://localhost/live/livestream
    ```

    Replace `./doc/source.flv` with any local video file. The stream will be available under the `live` application with the stream key `livestream`.
  </Tab>
  <Tab title="OBS Studio">
    Configure OBS Studio to push to your local SRS instance:

    1. Open OBS Studio and go to **Settings > Stream**.
    2. Set **Service** to `Custom...`.
    3. Set **Server** to `rtmp://localhost/live`.
    4. Set **Stream Key** to `livestream`.
    5. Click **OK**, then click **Start Streaming**.
  </Tab>
</Tabs>

</Step>

<Step title="Play the stream">

Once a stream is publishing, SRS makes it available in multiple formats simultaneously.

| Protocol  | URL                                              | Player                         |
|-----------|--------------------------------------------------|--------------------------------|
| RTMP      | `rtmp://localhost/live/livestream`               | VLC — Media > Open Network Stream |
| HTTP-FLV  | `http://localhost:8080/live/livestream.flv`      | Browser with srs-player        |
| HLS       | `http://localhost:8080/live/livestream.m3u8`     | VLC, Safari, or srs-player     |

To play in a browser, open the built-in web player at:

```
http://localhost:8080/players/srs_player.html
```

Set the stream URL to `livestream.flv` (HTTP-FLV) or `livestream.m3u8` (HLS) and click play.

</Step>

<Step title="Play with WebRTC">

WebRTC requires SRS to advertise its own reachable IP address to browsers as an ICE candidate. Pass your machine's IP using the `CANDIDATE` environment variable when starting the container:

```bash
docker run --rm -it \
  -p 1935:1935 \
  -p 1985:1985 \
  -p 8080:8080 \
  -p 8000:8000/udp \
  -p 10080:10080/udp \
  -e CANDIDATE="192.168.1.10" \
  ossrs/srs:6
```

Replace `192.168.1.10` with your machine's actual LAN or public IP address.

Open the WebRTC player at:

```
http://localhost:8080/players/rtc_player.html?autostart=true&stream=livestream
```

<Warning>
WebRTC will not work correctly if `CANDIDATE` is set to `localhost` or `127.0.0.1`. Always use the real network IP of the machine running SRS.
</Warning>

</Step>

</Steps>
