SRS is a simple, high-efficiency real-time media server built in C++. It supports a broad set of streaming protocols and codecs, making it suitable for live streaming, video conferencing, and IP camera integration at scale.

## What SRS supports

<CardGroup cols={3}>
  <Card title="RTMP" icon="video" href="/protocols/rtmp">
    Ingest streams from OBS, FFmpeg, or any RTMP encoder on port 1935.
  </Card>
  <Card title="WebRTC" icon="globe" href="/protocols/webrtc">
    Sub-second latency streaming with WHIP/WHEP on UDP port 8000.
  </Card>
  <Card title="HLS" icon="film" href="/protocols/hls">
    Deliver adaptive HLS streams to any device over HTTP.
  </Card>
  <Card title="HTTP-FLV" icon="play" href="/protocols/http-flv">
    Low-latency FLV delivery over plain HTTP for browser players.
  </Card>
  <Card title="SRT" icon="signal" href="/protocols/srt">
    Reliable UDP transport for contribution and production workflows.
  </Card>
  <Card title="MPEG-DASH" icon="chart-bar" href="/protocols/mpeg-dash">
    Adaptive bitrate streaming with MPEG-DASH manifests.
  </Card>

## Get started in 60 seconds

<Steps>
  <Step title="Run SRS with Docker">
    ```bash
    docker run --rm -it -p 1935:1935 -p 1985:1985 -p 8080:8080 \
        -p 8000:8000/udp -p 10080:10080/udp ossrs/srs:6
    ```
  </Step>
  <Step title="Publish a stream with FFmpeg">
    ```bash
    ffmpeg -re -i input.flv -c copy -f flv rtmp://localhost/live/livestream
    ```
    Or use OBS with server `rtmp://localhost/live` and stream key `livestream`.
  </Step>
  <Step title="Play your stream">
    Open `http://localhost:8080` to access the built-in player, or play directly:
    - **RTMP**: `rtmp://localhost/live/livestream`
    - **HLS**: `http://localhost:8080/live/livestream.m3u8`
    - **HTTP-FLV**: `http://localhost:8080/live/livestream.flv`
  </Step>
  <Step title="Explore the HTTP API">
    ```bash
    curl http://localhost:1985/api/v1/versions
    ```
    See the [API Reference](/api/overview) for the full API surface.
  </Step>
</Steps>
